# NeuroBench · 脑电实验台

给 Muse S Athena 头环用的 Windows 桌面程序，基于开源的 [OpenMuse](https://github.com/DominiqueMakowski/OpenMuse)（MIT 许可）。
主要功能：实时看脑电、电极贴合、频段占比、心率、前额血氧；一键录制、分步录制、意念开关、回看、长期趋势。

这个仓库只用来**发布程序和更新**。录制下来的脑电数据只存在你自己的电脑上，从不上传。

## 第一次安装
1. 在 [`releases/`](releases/) 里下载版本号最大的 `NeuroBench_v*.zip`。
2. 解压到一个固定位置，比如 `D:\NeuroBench`。
3. 双击 `Install.cmd`。需要联网，第一次大约下载 200 MB。
4. 桌面上会出现「NeuroBench 脑电实验台」图标。

## 自动更新
- 程序启动后检查一次更新，之后每 6 小时检查一次：
  - 先读本仓库的 `update.json`；
  - 读不到时，改走 jsDelivr 镜像（国内一般能访问）。
- 有新版本时，窗口顶部会出现提示，点「立即更新」，再点「立即重启」就行。正在录制时不会打扰你。
- 每个安装包都要核对 SHA-256，对不上就拒绝安装。新版本和旧版本分开存放，新版本打不开时会自动用回旧版本。右上角「···」菜单里可以手动「检查更新」，也可以「回退到上一版本」。
- 检查更新只下载 `update.json` 这一个文件，不会发送任何数据。
