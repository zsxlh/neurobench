# NeuroBench · 脑电实验台

给 Muse S Athena 头环用的 Windows 桌面程序，基于开源的 [OpenMuse](https://github.com/DominiqueMakowski/OpenMuse)（MIT 许可）。
主要功能：
- **实时**：脑电波形、逐个电极的贴合情况和调整提示、频段占比、心率与心率变异（多通道核对）、眨眼、肌电、晃动、前额血氧；一键录制全部信息。
- **冥想**：先校准 1 分钟，再用雨声和鸟叫实时反馈平静程度（可选脑电、心率或身体静止）；呼吸引导（共振呼吸）；成绩单和连续天数。
- **录制**：分步方案（练功前后对比、心理状态测评、过夜睡眠等），全程语音引导，录完填 10 秒小问卷。
- **报告**：心理状态测评报告、粗略的睡眠报告。
- **意念开关**：闭眼开关；想法训练（心算对放空），用你自己的数据训练分类器。
- **回看、趋势、个人**：自动剔除眨眼、肌电、晃动；和你自己平时比；个人基线、解锁进度、个人模型。
- **采集模式**：全功能、均衡、省电；显示电量还能用多久，低电量自动保存。
- **云端上传（可选）**：录完自动传到你自己的私有 GitHub 仓库，另一台电脑直接取用，不用手动拷文件。

这个仓库只用来**发布程序和更新**，里面没有任何录制数据。
录制默认只存在你自己的电脑上。只有在「···」→「云端上传设置」里填了你自己的访问令牌之后，录完才会上传到**你自己的私有仓库**；程序每次上传前都会确认那个仓库是私有的，公开仓库一律拒绝。令牌只存在本机的 Windows 凭据管理器里。

## 第一次安装
1. 在 [`releases/`](releases/) 里下载版本号最大的 `NeuroBench_v*.zip`。
2. 解压到一个固定位置，比如 `D:\NeuroBench`。
3. 双击 `Install.cmd`。需要联网，第一次大约下载 200 MB。
4. 桌面上会出现「NeuroBench 脑电实验台」图标。

## 自动更新
- 程序启动后检查一次更新，之后每 6 小时检查一次：
  - 先读本仓库的 `update.json`；
  - 读不到时，改走 jsDelivr 镜像（国内一般能访问）。
- 有新版本时，窗口顶部会出现提示，点「立即更新」，再点「立即重启」就行。正在录制时不会打扰你。
- 每个安装包都要核对 SHA-256，对不上就拒绝安装。新版本和旧版本分开存放，新版本打不开时会自动用回旧版本。右上角「···」菜单里可以手动「检查更新」，也可以「回退到上一版本」。
- 检查更新只下载 `update.json` 这一个文件，不会发送任何数据。
